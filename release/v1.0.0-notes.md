# DORAOps v1.0.0 — Stable reference

This owner-authorized GitHub Release identifies the exact tested commit for the
DORAOps v1 stable-reference boundary. It freezes the 47-symbol declared stable API
and 11 exact Git-blob schema identities recorded by the v1 contracts under `configs/`.

Publication waits for the latest successful CI, CodeQL, release-candidate, security,
evidence-integrity, deployment, control/evidence, incident-reporting and resilience-
assurance workflow runs on the same current `main` SHA. The tag is created at that
SHA, re-read, and never moved. An existing published release is never overwritten
or edited.

- Continuity/recovery objectives, exercises, findings, remediation and retest evidence.
- Human-owned incident-reporting workflow and deadline/receipt evidence structures.

## Boundaries

Stable describes the package/API/schema reference surface. It does not establish
DORA compliance, legal applicability, incident reportability, supervisory acceptance,
production security/resilience, successful disaster recovery, real-world control
effectiveness, certification, or production fitness.

No independent peer/security review is claimed. Live repository-governance
enforcement remains explicitly unverified. This publication does not upload a
package to a package index, publish a container, or deploy a service.
